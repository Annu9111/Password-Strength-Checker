# 🔐 Password Strength Checker

A simple and interactive **Password Strength Checker** built using **HTML, CSS, and JavaScript**.
This project evaluates the strength of a password in real-time and provides instant feedback to users.

* 🔍 Real-time password strength analysis

## 🧠 How It Works

The application checks password strength based on multiple conditions:

* Length of password
* Use of uppercase and lowercase letters
* Inclusion of numbers
* Presence of special characters

Based on these factors, it categorizes the password as:

* ❌ Weak
* ⚠️ Medium
* ✅ Strong
